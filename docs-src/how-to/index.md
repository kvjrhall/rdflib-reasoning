# How-To Guides

How-to guides are goal-oriented recipes for specific tasks. They should assume
the reader already knows the basic package shape and wants to accomplish one
thing reliably.

Planned guides include:

- Run RDFS materialization over an RDFLib graph.
- Retract asserted triples and inspect dependent inference removal.
- Enable contradiction diagnostics for an OWL 2 RL ruleset.
- Render or inspect a reconstructed proof.
- Configure middleware for dataset-backed Research Agent state.
- Configure vocabulary middleware for constrained RDF term use.

Until these pages are expanded, use the package guides and generated API
reference for current entry points.
