# Concepts

Concept pages explain the semantics and design tradeoffs needed to use the
packages correctly. They should complement, not duplicate, generated API
reference pages.

Planned concept topics include:

- RDFLib-backed materialization and support-aware retraction.
- RETE rule execution and derivation records.
- Contradiction diagnostics as non-mutating reasoning outputs.
- Graph-backed structural elements and RDF projection.
- Middleware-owned RDF state for Research Agent-facing workflows.
- Vocabulary constraints and term search as modeling support.

For current design context, see the development architecture pages.
