# Tutorials

Tutorials are learning-oriented walkthroughs for a first successful use of a
package capability.

The current tutorial path starts with checked-in notebooks while the Sphinx
tutorial pages are expanded:

- [RDFS inference notebook](../../notebooks/demo-rdfs-inference.ipynb): RDFLib-backed
  RDFS materialization and proof inspection for one inferred triple.
- [RDFS retraction notebook](../../notebooks/demo-rdfs-retraction.ipynb):
  support-aware retraction through ordinary RDFLib statement removal.
- [Contradiction rules notebook](../../notebooks/demo-contradiction-rules.ipynb):
  OWL 2 RL contradiction diagnostics when contradiction rules are enabled.
- [Proof reconstruction notebook](../../notebooks/demo-proof-reconstructor.ipynb):
  proof rendering, raw proof inspection, and fallback-to-leaf behavior.
